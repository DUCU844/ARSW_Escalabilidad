# Evidencias

Un archivo por parte del laboratorio, en el mismo orden que `docs/`. Llénalos a medida
que completas cada parte **en la consola de AWS**, no antes.

Convención para las capturas:

1. Guarda la imagen en `evidencias/img/`, con nombre `NN-descripcion.png` (ej.
   `01-sg-ec2-inbound.png`).
2. Referéncíala en el `.md` correspondiente con:
   `![descripcion](img/NN-descripcion.png)`

Cada archivo trae los campos mínimos a llenar (IDs, DNS, tiempos, valores de
métricas); agrega lo que consideres relevante para tu propio análisis.
